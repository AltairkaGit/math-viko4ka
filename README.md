# Викуся, всё получится ♡

23 небольших интерактивных урока и все 19 функций из учебных таблиц.

Сайт: https://altairkagit.github.io/math-viko4ka/

Откройте index.html локально или используйте GitHub Pages. Сборка и зависимости не нужны. Прогресс сохраняется в данном браузере.

Публикация автоматически запускается при изменениях в main. В Settings → Pages источником публикации должен быть GitHub Actions.

Файлы: index.html — страница, style.css — оформление, lessons.js — содержание, app.js — интерактивные графики и задания.
